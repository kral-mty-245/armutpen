# GitHub entegrasyonu kaldırıldı

NOMI AI içinden GitHub OAuth, repo oluşturma, push ve GitHub Pages yayınlama işlemleri iptal edilmiştir.

Eski OAuth endpoint'i artık `410 Gone` döndürür ve herhangi bir GitHub token'ı işleyemez.

Bu dosya, geçmiş kurulum notlarının yanlışlıkla kullanılmasını önlemek için korunmuştur.
